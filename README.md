## 02 / In the Dark

> **NarrativeOS** — 为中文长文与长篇小说作者构建的创作工作台。  
> 把上下文、证据与版本，组织成一座可以来回穿梭的图书馆。

<sub>Currently building in private. Some things are better revealed when they are ready.</sub>

### Principles

| LOCAL-FIRST | EDITABLE BY DESIGN | EVIDENCE OVER CONFIDENCE | COMPLETE LOOPS |
| :--- | :--- | :--- | :--- |
| 源文件与交付物，优先留在用户可控的环境。 | 不只展示结果，每个成果都应该能继续修改。 | 用渲染、测试与发布记录说明「为什么可以交」。 | 再小的工具，也要有入口、边界、诊断与交接。 |
